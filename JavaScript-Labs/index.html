Nội dung đã học

HTML

Tìm hiểu cấu trúc trang web, các thẻ HTML, liên kết, hình ảnh, danh sách, bảng và biểu mẫu.

CSS

Học cách định dạng giao diện, màu sắc, font chữ, bố cục, khoảng cách và thiết kế trang web responsive.

JavaScript & jQuery

Làm quen với biến, hàm, mảng, DOM, sự kiện, hiệu ứng chuyển động và xử lý dữ liệu.
